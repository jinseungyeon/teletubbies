## 다음 단계

2026-11-01 이동 구현 후속: 006의 임시 좌석 이동·복귀·자유 사유 저장을 구현하고 로컬 PostgreSQL 17에서 기존 시나리오 및 동시 요청 검증을 통과했다. 기본 사유와 자유 사유는 둘 중 하나만 사용하는 것으로 사용자 확정. 팀 영역은 동료와 공유하지 않아 BE 저장을 추가하지 않는다. **006은 원격 적용 전**이다. [자리 이동·복귀 API 및 적용 안내](./자리이동_복귀_API.md) 참조. 새 FE의 나머지 기능은 확정된 FE를 받은 뒤 결정한다.

집계 최종안 후속 기록: 사용자가 확정한 지수 감쇠·30분 구간 제곱근 보정·정규화 평균을 BE 계산 모듈로 구현했고 테스트 24개를 통과했다. [감각 집계 최종안](./감각_집계_최종안.md) 참조. 공간·항목별 실제 입력 시각·현재 근무/관측 범위는 향후 P2 조회 계층에서 제공해야 하며, 이번 계산 작업에서 Supabase SQL·RPC·FE를 변경하지 않았다. 재확인·환경 변화 감지·신뢰도·의견 불일치·추가 알림도 구현하지 않았다.

2026-11-01 추가: 실제 FE ID에 맞춘 004·005를 로컬 검증한 후 사용자가 Supabase 적용과 기본 조회를 확인했다. 실제 사용자 세션의 API 통합 검증과 FE 어댑터 연결은 남아 있다. AI 생성은 사용자가 보류했다. [FE 코드 연동 검토](./FE_코드_연동_검토.md) 참조.

1. Auth 이메일 로그인·이메일 확인 설정 확인.
2. 실제 계정 가입·로그인 및 사용자 세션으로 RPC 호출 확인.
3. 회사 가입 → 좌석 선택 → 출근 → 메시지·감각 입력 → 퇴근의 전체 흐름 확인.
4. 다른 직원·다른 회사 권한과 실제 지도 다운로드 검증.

SQL Editor의 운영자 조회로 설치·지도 경로·카탈로그는 확인했지만, 실제 직원 세션의 API·지도 접근 권한과 signed URL 발급은 아직 검증하지 않았다. 001·002·004를 다시 실행하지 않는다. 003 재실행은 현재 가입 코드를 교체하므로 필요할 때만 수행한다.
